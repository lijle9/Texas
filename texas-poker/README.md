# 联机德州扑克游戏

一个轻量的浏览器端联机德州扑克游戏，支持3-4名好友跨设备游玩，无需安装额外软件，仅需浏览器即可加入游戏。

## 项目特点
- 🌐 跨设备联机：好友可通过手机、电脑等任意设备访问，无需在同一网络
- 🚀 极简部署：一键部署到免费云服务，无需服务器运维
- ⚡ 实时同步：基于WebSocket实现低延迟实时状态同步
- 🎮 标准规则：完整的德州扑克游戏流程，支持盲注、下注、比牌结算
- 📦 无依赖：前端无需打包，直接加载即可使用

## 技术栈
- 后端：Python + Flask + Flask-SocketIO
- 牌型评估：Treys（专业德州扑克牌型评估库）
- 前端：原生HTML+CSS+JS + Tailwind CSS
- 部署：Render 免费云服务

## 本地运行
如果你想在本地测试运行，可以按照以下步骤操作：

1. 进入项目目录
```bash
cd texas-poker
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 启动服务
```bash
python app.py
```

4. 打开浏览器访问 `http://localhost:5000` 即可开始游戏

## 部署到公网（Render）
我们使用Render免费版服务来部署，提供公网访问地址，好友可以直接访问：

### 步骤1：代码托管到GitHub
1. 注册/登录GitHub账号
2. 创建一个新的公开/私有仓库
3. 将本项目的所有文件上传到这个仓库（可以直接上传，或者用git推送）

### 步骤2：Render创建服务
1. 注册/登录[Render官网](https://render.com/)（免费注册即可）
2. 点击右上角 `New` -> 选择 `Web Service`
3. 连接你的GitHub账号，选择刚才创建的项目仓库
4. 配置服务信息：
   - **Language**: 选择 `Python 3`
   - **Build Command**: 填写 `pip install -r requirements.txt`
   - **Start Command**: 填写 `gunicorn --worker-class gevent --bind 0.0.0.0:$PORT app:app`
   - **Plan**: 选择免费的 `Free` 计划
5. 点击 `Create Web Service` 等待部署完成

部署完成后，你会得到一个公网访问地址，类似 `https://your-poker-game.onrender.com`

## 好友使用流程
1. 将部署好的公网地址分享给你的好友
2. 你和好友都在浏览器打开这个地址，输入自己的昵称
3. 你点击「创建房间」，会得到一个6位的房间号，分享给好友
4. 好友在页面输入房间号，点击「加入房间」
5. 所有玩家都点击「准备」按钮，游戏会自动开始
6. 按照界面提示进行游戏，所有操作都会实时同步给所有玩家

## 注意事项
1. **Render休眠机制**：免费版Render实例在30分钟无活动后会自动休眠，下次访问时会自动唤醒，唤醒需要3-5秒，建议玩之前提前打开页面
2. **数据存储**：本项目使用内存存储，服务重启后所有房间数据会清空，不过好友局都是临时的，不影响使用
3. **人数限制**：单房间最多支持4名玩家，完全满足3-4人好友局的需求
4. **重连机制**：前端会自动处理网络波动和重连，即使短暂断网也能自动恢复
